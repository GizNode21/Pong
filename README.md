# Pong

A browser remake of Atari's 1972 Pong. Single HTML file, no build step.

Open `index.html` in a browser to play.

## Controls

| Action | Keys |
| --- | --- |
| Left paddle | `W` / `S` (1-player mode also accepts `↑` / `↓`) |
| Right paddle (2-player) | `↑` / `↓` |
| Serve / pause / resume | `Space` (`P` also pauses) |
| Touch | Tap to serve, drag on your half of the screen |

First to 11 points wins.
